# Maths game: Resources

## Knowledge

- [MDN: Client-Server overview](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/First_steps/Client-Server_overview)
  Plain-language intro to clients, servers, requests and responses. Use for: lesson 1-level basics.
- [MDN: Introduction to the server side](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/First_steps/Introduction)
  What server-side code is for and why it exists. Use for: "why do we need a server at all".
- [MDN: An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview)
  The shape of HTTP messages, methods, status codes, headers. Use for: HTTP basics before RFCs.
- [RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110)
  The actual standard. Use for: settling any precise question about methods, status codes, idempotency.
- [Julia Evans: HTTP zine (wizardzines)](https://wizardzines.com/zines/http/)
  Visual, beginner-friendly HTTP. Use for: drawings-first explanations.
- [Everything curl](https://everything.curl.dev/)
  The official curl book. Use for: every hands-on HTTP exercise.
- [Sriniously: Backend from First Principles notes](https://backend-from-first-principle.vercel.app/)
  Companion notes to the YouTube series. Use for: ch. 1 (HTTP), 2 (routing), 3 (serialization), 6 (controllers/services), 20 (concurrency), 24 (WebSockets).
- [Kotlin + Spring Boot getting started (JetBrains)](https://kotlinlang.org/docs/jvm-get-started-spring-boot.html)
  Official Kotlin-flavoured Spring Boot tutorial. Use for: project creation, first controller.
- [Spring guide: Building a RESTful Web Service](https://spring.io/guides/gs/rest-service)
  The canonical first Spring endpoint. Use for: controllers, JSON responses.
- [Spring Boot reference docs](https://docs.spring.io/spring-boot/index.html)
  Use for: configuration, starters, anything Spring Boot does automatically.
- [Spring Framework: WebSockets](https://docs.spring.io/spring-framework/reference/web/websocket.html)
  Use for: the push lessons.
- [MDN: WebSockets API](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API) and [RFC 6455](https://www.rfc-editor.org/rfc/rfc6455)
  Use for: what a WebSocket is, the handshake, ping/pong.
- [Kotlin stdlib: Random](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.random/-random/)
  Use for: seeded question generation (same seed → same questions).

## Wisdom (Communities)

- [Kotlin community (official Slack and forums)](https://kotlinlang.org/community/)
  Active, moderated. Use for: Kotlin and Spring-with-Kotlin questions.
- [r/SpringBoot](https://www.reddit.com/r/SpringBoot/) and [r/Kotlin](https://www.reddit.com/r/Kotlin/)
  Use for: design critique, "is this how people do it?" questions.
